# コメ読みちゃん 使い方

自分の TikTok LIVE のコメントやギフトを、このアプリのコメント画面で見ながら、配信画面の上にコメント列として出し、Windows 内蔵TTS または VOICEVOX で読み上げます。

TikTok LIVE Studio のリンクソースと、OBS のブラウザソースに、それぞれ用の URL を 1 本足す使い方です。ギフトの公式演出やフォロー音は TikFinity 側のままで問題ありません。

> **個人・身内利用向け**  
> TikTok 側の仕様変更で動かなくなることがあります。

## 準備

1. コメ読みちゃん を起動する（最初に、やることを3つ出します。下にコメント欄も見えます。**サンプルを見る** で例の行を出せます。案内はそのままです。**サンプルを消す** で消せます）。デスクトップのショートカットが Electron の絵のままだったら、一度起動してからショートカットを作り直してください
2. 画面の案内どおり、TikTok ID を入れて **接続** し、出てきたアイコンと名前が自分か確認する
3. コメントを自分で見るだけなら、これで使えます。視聴者の画面にも出すときは、設定の **LIVE Studio用をコピー** を使います

読み上げは最初から Windows 内蔵TTS です。VOICEVOX にしたいときは、あとから読み上げタブで変えられます。VOICEVOX を選んでいても、本体が起動していないときは内蔵TTSで読み上げます。

## 初期設定

アプリが案内します。

1. **設定で ID を入れる**（先頭の `@` は不要）
2. **接続する** → アイコンと名前が出るので、自分か確認して **この人で接続**
3. TikTok で配信を開始する（LIVE Studio でもスマホでも可）

コメント欄の見た目は、最初から下に空の欄が出ます。**サンプルを見る** でコメント・ギフト・フォローの例を出せます（音は出ません。配信ソースにも出ません）。案内はそのまま残ります。同じ案内の **サンプルを消す** で消せます。上の **サンプル** の **コメント画面を消す** でも同じです。

接続できるとコメント画面に流れます。視聴者の画面にコメント列を乗せるときは、オーバーレイタブの **コメント** で **LIVE Studio用をコピー** を LIVE Studio の **ソース追加 → リンク** に貼ります。ギフトなどの中央演出は **アラート**、いいね／ダイヤのランキングは **ランキング** の URL を、別のソースとして追加して貼ります（コメント列と同時でも構いません）。貼ったあとは、設定画面の上部、接続の横の **サンプルを出す** でコメント・ランキング・アラートをまとめて確認できます（**表示を消す** で消せます）。コメント画面ではこのボタンは出ません。配置に載せた同じ種類にも出ます。

毎回自動で始めたいときは、接続タブの **起動時に配信へ接続する** をオンにします。起動時につながるのは、一度アイコンと名前で確認した ID だけです。

接続・切断はコメント画面のままで使えます。読み上げを飛ばす／待ちを捨てる／固定枠の待ちを捨てる／一時停止／サウンドミュートは上部の **操作** メニューにあります。初期は **F8** で今の読み上げを飛ばし、**F9** で読み上げの待ちを捨て、**F10** で固定枠の表示と待ちを捨て、**F7** で一時停止、**F6** でサウンドミュートです（入力欄にいるときは効きません。キーはアプリタブで変えたり消したりできます。同じキーは使えません。Shift や Ctrl との組み合わせも使えます。消しても画面のボタンは使えます）。上の **窓** から **手前に置く** と **コンパクトな窓** を切り替えられます。最小化・最大化・閉じるはタイトルバー右の ─／□／× です。手前・コンパクトはアプリタブからも変えられます。窓の位置・大きさと最大化は次回起動時に覚えます（プロファイルには含みません。画面の外に出ていたときは見える位置へ戻します）。上の **サンプル** からコメント画面／配信ソースのサンプルと消去ができます。配信ソースのサンプルは **オーバーレイ** タブにもあります。ログの保存はアプリタブです。

設定のタブは次のとおりです。

- **接続** … TikTok ID、起動時に接続する
- **フィルタ** … NGワード、ブロックするユーザー、ミュートするユーザー、呼び方（表示名・読み上げ名の差し替え）、読み替え辞書（コメントの読み上げだけ言葉を置き換え）
- **コメント** … 文言（読み上げ／サウンド）、バッジ、読み上げ条件
- **ギフト / イベント** … 配信ソースへの表示と読み上げ／サウンド。イベントは種類を選んで1つずつ出す
- **オーバーレイ** … 配信ソースの URL と見た目。区分はコメント／ランキング／アラート。このタブだけプレビューが出る（通常は右、狭い窓では上）。ランキングを開くとプレビューもランキングになる。幅は境界をドラッグして変えられる（狭い窓では縦積みのためドラッグなし）
- **読み上げ** … 声とエンジン
- **アプリ** … 常に手前、コンパクト窓、トレイ常駐、アプリの明るさ、ショートカット、プロファイル、ログの保存、プロファイルの書き出し／読み込み／初期化。各タブの一番下にも、そのタブだけ戻す初期化があります

### コメント画面のレイアウト

コメント画面は左がコメント、右がギフト・フォローなどです。上の **まとめる / 分ける / 自由配置** で欄を変えられます。まとめるは 1 列、分けるはコメントとその他の 2 列です。分けているときは境界をドラッグすると幅を変えられます。ダブルクリックで初期の幅に戻ります。

**自由配置** では欄の見出しを他の欄の端へドラッグすると左右・上下に分割できます。種類のラベルを中央へドロップするとその欄へ移せます。窓の数は、今表示している種類の数までです。表示をオフにした種類だけの窓は消えます。まとめる／分ける／自由配置と、自由配置での移動は変えたときに保存されます。上の **文字** スライダーでコメント画面の文字の大きさを変えられます（10〜30px、初期は20px。配信ソースの見た目は変わりません）。

### コメント画面のバッジ

ファンクラブ加入者は名前の左にバッジが出ます。TikTok のファンクラブ名が取れたら **ゆうれい5** のように名前とレベ、取れなければ **メンレベ5** です。停止中（しばらくポイントが無い人）は同じバッジの色が灰色になります。未加入はバッジなしです。色はコメントタブの **メンレベの色** で、境目（初期は 1 / 10 / 15 / 20 / 25）と色を変えられます。スーパーファンは **スパファン**、配信のモデレーターは **モデ**、配信者本人は **配信者** と出ます。ギフトはダイヤ数が大きいほど左の色が目立ちます（灰 → 黄 → 橙 → ピンク）。

### コメント画面の表示と検索

上の **この画面** で、ギフト・フォロー・シェア・スパファン・宝箱・ポータル・いいね・入室をコメント画面に出すかを切り替えます（配信ソースと読み上げは変わりません。読み上げは設定の各タブです）。オンの種類は色が付きます。コメントは常に出ます。各タブの **配信ソース** をオフにしていても、コメント画面の **この画面** がオンならこちらに出ます。お楽しみ袋はギフトとして出ます。ポータル経由の入室は **入室** の表示に従います。

**検索** に名前・ID・本文を入れると、一致しない行を隠します。行をクリックすると、同じ人の行だけが目立つようになります。もう一度クリックするか、余白をクリックすると解除します。

### コメント画面の右クリック

行を右クリックすると、**コメントをコピー** / **IDをコピー** / **ニックネームをコピー**、その人の **ミュート**（読み上げしない）、**ブロック**（表示も読み上げもしない）、**呼び方を変える／消す** ができます。IDは @ なしです。

### コメント画面のログ

古い行は設定の **コメント画面の最大行数**（デフォルト 1000、100〜5000）を超えると消えます。アプリを閉じた時点のログは次回起動時に復元されます。設定を減らしても今表示中の行はすぐ消えません。上にスクロールしているときはその欄だけ自動では下りず、**最新へ** で最新に戻れます。上の **サンプル** の **コメント画面にサンプル** で、コメント・ギフト・フォローの例を音なしで出せます（配信ソースには出ません）。**ログを消す** は表示と保存済みログを消します（確認ダイアログが出ます）。各窓の右上の **消す** は、その窓の行だけ消します（こちらも確認が出ます）。設定画面の、接続の横の **サンプルを出す** は、コメント・ランキング・アラートの配信ソースと、配置に載せた同じ種類にサンプルを出します。コメント画面では出ません。コメント列は一度空にしてからコメント・ギフト・フォローの例を出し、固定枠がオンならギフトはコメントのすぐ上、フォローはそのあと枠に切り替わります。ランキングとアラートは **表示を消す** まで繰り返します。配信中に押すと、配信ソフトに貼った画面もサンプルに切り替わります。**表示を消す** は配信ソースと配置のサンプルを消します（コメント画面は変わりません）。アプリタブの **ログを保存** で、アプリを開いてから流れた行をテキスト（txt）に書き出せます。中身はタブ区切りなので、表計算ソフトでも開けます。

### TikTok LIVE Studio

1. ソース追加 → **リンク**
2. オーバーレイタブで区分（コメント／アラート／ランキング）を選ぶ
3. **LIVE Studio用をコピー** したアドレスを貼る（`127.0.0.1` は弾かれます）
4. 通らないときだけ **別のURLをコピー**（`overlay.localhost`）を試す
5. 位置とサイズを調整する
6. ブラウザソースの音声はオフで大丈夫です（読み上げ・効果音はアプリ本体から出ます）

### OBS（録画）

1. ソース追加 → **ブラウザ**
2. オーバーレイタブで区分を選び、**OBS用をコピー**（`127.0.0.1`）を貼る
3. 幅・高さはシーンに合わせる
4. ブラウザソースの音声モニタリングはオフで大丈夫です（読み上げ・効果音はアプリ本体から出ます）
5. 配信や録画に音を載せたいときは、アプリの音声をキャプチャしてください

## テンプレート

コメントとギフトは、表示と読み上げを別々に書けます。変数以外の文章もそのまま使えます。

| 変数 | 内容 |
|---|---|
| `{user}` | ニックネーム（色はユーザーごとの名前色） |
| `{comment}` | コメント本文 |
| `{gift}` | ギフト名 |
| `{count}` | ギフト個数。1個のときは空。2個以上は表示が `×100`、読み上げが `100こ` |
| `{likes}` | いいねの累計（数字のまま） |
| `{event}` | イベントの短い名前（フォロー／シェア／スーパーファン／宝箱／ポータル／いいね／入室など） |

`@` や `＠` で始まるコメントは、コメントタブの **@から始まるコメントは読み上げない** がオンなら表示だけします。**URLは読み上げない** がオンなら、http / www / discord.gg のリンクは読みません。文言があるコメントはリンクの部分だけ飛ばし、リンクだけのときは名前も読みません。**配信者のコメントは読み上げない** がオンなら、配信者本人のコメントは表示だけします。**絵文字だけのコメントは読み上げない** は初期オンで、スタンプや絵文字だけのコメントは読みません。

**条件を満たすコメントだけ読む** をオンにすると、下の条件を満たすコメントだけ読みます。初期はオフで、全員読みます。**メンレベも読む** をオンにすると **メンレベは何以上を読む** が使えます。オフにするとメンレベは読まず、**スーパーファンは読む** だけにできます。メンレベ未加入のスーパーファンも、スーパーファンは読むがオンなら読みます。ギフトやフォローの読み上げはこの条件の外です。**同じ人の連投は読み上げない**（最初はオフ）は、短い間隔で同じ人が続けて書いたコメントを表示だけにします。間隔は秒で変えられます。

フィルタタブの **ブロックするユーザー** に TikTok ID か表示名を追加すると、その人のコメント・ギフトなどは表示も読み上げもしません。**ミュートするユーザー** は読み上げだけ止めます。NGワードは文言、ブロックとミュートは人です。どれも追加欄と行の **×** で編集します。コメント画面の右クリックからも追加・解除できます。

**呼び方** では、TikTok ID ごとに読み上げと画面に出す名前を差し替えます（読み替え辞書とは別の機能です）。右クリックの **呼び方を変える／消す** からも変えられます。次回起動後も残ります。

フィルタタブの **読み替え辞書** では、コメントの読み上げだけ言葉を置き換えます。「変換前」と「変換後」を入れて追加します。ギフト名やフォローなどは変わりません。上限は 2000 件です。**書き出す** でテキストファイルに保存し、**読み込む** で置き換え（確認が出ます）できます。**全部クリア** も確認が出ます。

コメントタブの文言では、読み上げオンのとき **読み上げ**／**サウンド** を選べます（ギフトの読み上げ／サウンドと同じ考え方です。どちらか一方だけです）。読み上げのときはテンプレートが出ます。サウンドのときは音と音量（0〜500・初期100）の設定が出て、TTS は出さず効果音だけ鳴らします。**選択** で音を差し替え、再生アイコンで試し聞き、**×** でテンプレ音に戻せます。読み上げもサウンドもアプリ本体から出ます（配信ソースには鳴りません。読み上げチェックがオフのときも鳴りません）。画面上の **操作** メニューの **サウンドをミュート**（初期 F6）は、設定を変えずに一時的に止めます。

イベントタブ（フォロー／シェア／スパファン／宝箱／ポータル／いいね／入室）も同じです。音を出すオンのとき **読み上げ**／**サウンド** を選べます。読み上げのときは読み上げテンプレートだけが出ます。サウンドのときは種類ごとに1つの効果音と音量（0〜500・初期100）です（スパファンの加入とボックス、入室の通常とポータル経由も、それぞれ共通の音・音量です）。**選択**・再生アイコン・**×**（テンプレに戻す）もコメントと同じです。

**名前を出さない**（オーバーレイタブ）をオンにすると、配信ソースのコメント列からニックネームが消えます。ギフトやフォローの表示にも効きます。このアプリのコメント画面には名前が出ます。読み上げはテンプレートのままです。

表示・読み上げテンプレートでは、欄の上のボタンで `{user}` `{gift}` `{event}` などを挿入できます。表示欄では差し込み横の色で強調色を変えられ、固定枠・コメント列・イベントアラートで同じ色・太字で出ます。差し込み以外の平文は吹き出しの文字色です。`{user}` だけはユーザーごとの名前色のままです。差し込み色が初期（またはかんたん見た目用）のままなら、**かんたん見た目** のプリセットに合わせて変わります。自分で変えた色はそのままです。

自分で書いた文言だけ色付き太字にしたいときは、`**強調したい文字**` のように囲みます。色は `**…**` 専用の色ピッカーで変えられます。読み上げでは `**` を外して中身だけ読みます。

読み上げテンプレートの **半角ピリオド `.`** は無音の拍です。句点にしたいときは `。` を使ってください。

例:

- `{user}.{comment}` → テストユーザー（拍）テストコメントです
- `{user}さんから{gift}{count}` → 1個なら `テストさんからバラ`、100個なら表示 `テストさんからバラ×100`
- `{user}さんが{event}しました` → フォローなら `テストユーザーさんがフォローしました`
- `**初**{event}` → 表示は「初」だけ強調色、読み上げは「初フォロー」のように中身だけ

設定は変えたらすぐ保存されます。数字が範囲外のときは保存せず、画面下に知らせます。直すとその内容で保存されます。

## いいね

いいねは視聴者ごとに数えます。イベントタブで区切り（例: 100）を指定すると、その人の累計が 100・200・300… をまたいだときだけ表示／音出しします。連打そのものは出しません。

**ランキング** はコメント列とは別の配信ソースです。配信に接続しているあいだの累計トップを出し続けます（接続し直すとリセット）。オーバーレイタブの **ランキング** に、出す／出さない・いいね／ダイヤの切替・表示人数（1〜10・初期5）・見た目があります。いいねのときは **いいねの更新**（常時／ポーリング）も出ます。ポーリングは 1〜300 秒（初期 30）ごとに配信ソースへ送ります。ダイヤは常に即時です。見た目では **入れ替わりの動き**（スライド／ふわっと／スライド＋強調・初期スライド）と **速さ**（遅い／ふつう／速い・初期ふつう）も変えられます。URL をコピーして別ソースとして貼ってください。ダイヤは通常ギフトの個数×ダイヤの累計で、宝箱・ポータル・スパファンボックスは含みません。初期はオン・いいね・常時です。件数の横は、いいねならハート、ダイヤならダイヤのアイコンです。見た目の **アイコン（ハート／ダイヤ）を付ける** をオフにすると数字だけになります。右のプレビューにサンプルが出ます。配信ソースへ出すときは、設定画面の、接続の横の **サンプルを出す** です。URL パスは `/overlay/ranking/` です（以前の `/overlay/likes/` は新しい方へ転送されます）。

## ポータル

ポータルを投げたときはイベントタブの **ポータル** で表示・音出しします。経由入室は **入室** の表示・音出しに従い、文言だけ分けます（通常は `{user}さんが{event}しました`、経由は `ポータルから{user}さんが{event}しました`。`{event}` はどちらも「入室」です）。コメント画面の **表示** も、投げはポータル、経由入室は入室です。初期は投げがオン、入室がオフです。

## VOICEVOX

1. [VOICEVOX](https://voicevox.hiroshiba.jp/) を入れる（エンジンは通常 `127.0.0.1:50021`）
2. 読み上げタブでエンジンを **VOICEVOX** にする
3. **VOICEVOXの場所** が空なら、よくあるインストール先を探します。見つからなければ **参照** で `VOICEVOX.exe` を選ぶ
4. **VOICEVOXを起動** を押す（または VOICEVOX 本体を自分で起動する）
5. 声の横の **声を再取得** でキャラを選ぶ
6. 毎回一緒に立ち上げたいときは **コメ読みちゃん起動時にVOICEVOXも起動する** をオンにする
7. **クレジットをコピー** して、TikTok / YouTube などの**概要欄やパネル**に貼る

このアプリを終了しても VOICEVOX は閉じません。使うキャラの利用規約でクレジットが必要な場合、アプリ内に書いてあるだけでは足りません。視聴者が見られる場所に `VOICEVOX:ずんだもん` のように載せてください。

## オーバーレイ

**オーバーレイ** タブは視聴者の画面（配信ソース）用です。コメント画面の文字サイズや欄は、コメント画面の上で変えます。このタブを開くとプレビューが出ます（通常は右側。コンパクトな窓など横が狭いときは上に積まれます）。境界をドラッグすると幅を変えられます（縦積みのときはドラッグしません）。ダブルクリックで元の幅に戻します。市松模様は「背景が透明かどうか」を見るためのもので、LIVE Studio / OBS に貼ったソースの背景は透明のままです。グリーンやマゼンタにも切り替えられます（コメントの **かんたん見た目**）。他の設定タブではプレビューは出しません。上に配信ソースの URL があります。サンプルは設定画面の上部、接続の横の **サンプルを出す** / **表示を消す** で、コメント・ランキング・アラートをまとめて出します。コメント画面ではこのボタンは出ません。区分は **コメント** / **ランキング** / **アラート** です。コメントの中は **かんたん見た目** / **コメントと固定枠** / **名前と色** です。ランキングを開くと、右のプレビューがランキングのサンプルに切り替わります。**配置** では、横（1920×1080）と縦（1080×1920）の配信ソースを何枚でも追加できます。切り替えは上の配置一覧から選び、名前は「配置名を変える」で付けられます。配置が1枚もないときは、追加以外は出ません。項目の名前は、レイヤーを右クリックして「項目名を変える」です。設定画面の、接続の横の **サンプルを出す** で、編集中のキャンバスと配信ソフトに貼った配置にも中身が出ます。表示を消すまで繰り返します。テンプレートはコメント・ランキング・アラートが入った状態、空白は何も無い状態です。左のレイヤーで重ね順と表示を変え、キャンバスでドラッグでき、端や角をドラッグすると縦横比を保ったまま中身も一緒に縮小・拡大します。キャンバスの端やほかの項目に近づくと吸い付きます。枠の外をクリックすると選択が外れます。Alt を押しながら端や角をドラッグすると、中身の大きさはそのままで枠だけ切ります。切った辺は赤くなります。右クリックから名前、表示、重ね順、複製、削除、その配置だけの設定を開けます。非表示にしても左のレイヤーには残り、目のマークでもう一度表示できます。行のゴミ箱でも削除できます。レイヤーは行の上半分へドロップするとその手前、下半分へドロップするとその奥に入り、一番上と一番下にも置けます。設定の項目はコメント・ランキング・アラートそれぞれのオーバーレイ設定に揃えています。ランキングの列幅は枠の幅です。いいねとダイヤの更新も、配置ごとに常時かポーリングかを使います。各配置の URL を LIVE Studio の縦と横、OBS に貼ります。アラートを開くと、同じプレビューにサンプルが繰り返し出ます。**サンプルを出す** を押すと、配信ソースでも同じサンプルが繰り返し出ます（プレビューはそのまま続きます）。**表示を消す** で配信ソース側だけ止まります。アラートの画像や文言はイベントタブです。

**かんたん見た目** サブタブで、CSS を書かなくても変えられます。**動き** でコメントの出方（ふわっと／フェード／スライドなど）を選べます。**速さ** はとても遅い〜とても速いの5段階です。初期値はふわっと・ふつうです。色のプリセットを押しても動きは変わりません。配信中に変えたときは、次に出る行から効きます。プレビューは選ぶと再生されます。**動きを見る** でももう一度確認できます。

1. プリセットを選ぶ（標準 / 明るい / 文字だけ / ネオン）
2. フォント・文字サイズ（10〜30px、初期は20px）・背景の濃さ・角の丸み・ギフトアイコン・位置を調整する。ネオンを選ぶと **ネオンの色** バーが出ます
3. プレビューで確認する（最初からコメント／ギフト／フォローの例が出ています。スライダーとフォントはすぐ反映されます）
4. スライダーを動かすと、少し待って配信ソースにも保存されます

表示行数・表示時間・**文字数上限** は **コメントと固定枠** サブタブにあります。長いコメントは … で切れます。**時間で消えない** をオンにすると、秒数では消えず、表示行数を超えた古い行だけ消えます。

ランキング配信ソースの見た目は、オーバーレイタブの **ランキング** にあります（プリセット・文字サイズ・背景・角丸・アイコン・行間・パネル幅など。ネオンでは色相バーが出ます）。

**イベントアラート** はコメント列とは別の配信ソースです。ギフト／フォローなどの各イベントで **イベントアラート** をオンにすると、中央に文言と画像（または GIF）が出ます（コメントにはありません）。初期のオン／オフは、そのイベントの読み上げと同じです。ギフトの初期画像は **もらったギフトの画像** で、取れないときは同梱GIFを出します。他の種類は同梱GIFです。スパファン加入とスパファンボックス、ポータル設置とポータル入室、通常入室はそれぞれ別の画像です。**画像を選ぶ** で差し替え、**×** で初期（ギフトはもらったギフト、他はテンプレ）に戻せます。選んでいない画像ファイルは設定保存時に消えます（効果音も、どこからも選ばれていないファイルは同様です）。表示時間は各イベントのアラート設定で種類ごとに変えられます（初期4秒、1〜120秒）。長い文言は2行で切れ、末尾は … になります。固定枠やコメント列と同時に出しても問題ありません。テスト送信でも、アラート用ソースが繋がっていれば確認できます。イベントアラートのユーザー名も、見た目タブの **名前の色** と同じパレットが付きます。

同じ **コメントと固定枠** サブタブに **固定枠** があります。**固定枠を使う** をオフにすると、今までどおり全部下から流れます。オンのとき、ギフト・フォローなどはコメント列のすぐ上に1件ずつ出します。来た順で、今の行が消えてから次です。枠の色はコメント列と違います（標準はオレンジ、ネオンは今の色からずらした色）。動きはコメントと同じテンプレートです。初期の表示時間は4秒です。**次が無いときは出したまま** をオンにすると、待ちが無ければ枠を消しません。次が来たら今の秒数のあと切り替わります。種類ごとに「固定枠に出す／コメントと一緒に流す」も選べます。さらに、固定枠に出す各種類の横に秒数を入れると、その種類だけ個別の表示時間にできます（空なら共通の秒数）。初期はコメント以外が全部固定枠です。配信中に変えたときは、今出している行はそのまま、待ちに入っている分から今の種類に従います。固定枠をオフにしたときや、出す種類が無くなったときは、出しっぱなしでも枠を消します。表示時間の途中なら、その秒数が終わるまで今の行は残ります。配信ソースは常にこの設定です。プレビューも固定枠で見るとき、種類は表示時間ごとに順に切り替わります。プレビューだけ、今までどおり全部流れる見え方にも切り替えられます。コメント画面には固定枠は出ません。待ちが溜まったときは画面上の **固定枠の待ちを捨てる**（初期 F10）で、今の表示も待ちもすぐ消えます。**配信ソースを消す** はコメント列も固定枠も消します。配信ソフトに貼った画面が古いときは、ブラウザソースを更新してください。

**名前と色** サブタブの **名前の色** では、配信ソースのコメント列でユーザー名に色を付けられます。同じユーザーは常に同じ色になります（固定枠やイベントアラートにも付きます）。5色のパレットを自由に変更できます。初期のパレットのまま（またはかんたん見た目用の色のまま）なら、**かんたん見た目** のプリセットに合わせて見やすい色へ自動で変わります。自分で変えた色はそのままです。各イベントの表示テンプレにある**差し込み色**も同じルールです（初期またはかんたん見た目用のままならプリセットに合わせ、自分で変えた色はそのまま）。オフにすると名前の色付けを無効にします。

上級者向けのカスタム CSS は、同じ **名前と色** サブタブに折りたたんであります。空ならかんたん設定のままです。効くのはコメント列の配信ソースだけで、イベントアラート・ランキングには入りません。開くと、HTML の骨格・クラス・よく使う CSS 変数の一覧が出ます。

ギフトが来ると、コメント列の右に **そのギフトの TikTok アイコン** が出ます。ギフトタブでは **配信ソース**（表示）と **読み上げ**（音・TTS）を切り替えます。表示テンプレートは常に編集できます。読み上げをオフにすると、読み上げもサウンドも出しません。読み上げをオンにすると、**読み上げ**／**サウンド** のどちらかを選べます。読み上げのときは読み上げテンプレートと **読み上げする最低ダイヤ** が出ます（最低ダイヤより安いギフトは表示だけして読みません。投げたポータルにも同じ最低ダイヤが効きます）。サウンドのときは分け方（ギフトの種類／ダイヤ数）と音量の設定が出ます。音はアプリ本体だけ鳴ります（配信ソースには鳴りません。配信に載せたいときは OBS などでアプリの音声をキャプチャしてください）。ギフトのテンプレ音はチャリン系で、コメントのサウンド（ピッ）とは別です。**ギフトの種類** のときは共通の音・共通の音量と一覧が出ます（共通の音も再生アイコンで試し聞き、**選択** で差し替え、**×** でテンプレに戻せます）。テンプレ音（個別ファイルを選んでいないギフト）の音量は **共通の音量** でまとめて変えます。一覧ではオン／オフと個別音・音量・再生を設定できます（初期はすべてオフ。鳴らすギフトだけオン。名前・ダイヤで検索できます。**全選択**／**全外し** は今の検索結果だけに効きます。検索が空なら一覧全部です。行は再生・有効・ギフト・サウンド・音量の並びです。ギフト・サウンド・音量の列はヘッダ右端をドラッグして幅を変えられます。再生ボタンはテスト中は停止に切り替わり、もう一度押すと止められます。一覧の音量バーは個別ファイル音のときだけ変えられます（テンプレ音の行は共通の音量の表示だけで変更できません）。音量は 0〜500（初期 100。小さい音源は 100 より上げて調整）。読み上げモードの TTS には効きません。カタログに無い・IDが取れないギフトは一覧に出ないため、オンにできません。個別音は **×** でテンプレに戻せます（右クリックでも可）。取り込んだ効果音は元のファイル名のまま表示され、同名は上書きされます）。**ダイヤ数** のときは共通の音は出ず、下限〜上限の帯を追加して帯ごとに音と音量（0〜500）を選べます（上限を空にするとそれ以上全部。どの帯にも入らないダイヤは鳴らしません。帯が重なると保存できません。帯でも再生アイコンで試し聞き、**×** で帯を削除できます）。最初からよくあるギフトの一覧が入っています。配信中に届いたギフトは自動で足され、日本語名なら上書きして保存されます。**一覧を再取得** は普段は不要です。まとめて取り直したいときだけ使ってください（配信接続中がいちばん取りやすい。配信前は部屋が見つからず失敗することがあります。`.env` の `EULER_API_KEY` が必要なこともあります）。**0件のときだけ** Euler Business プランの案内が出ます。ギフトタブでテストするギフトを選べます。一覧が空のときは仮のバラになります。

読み上げの文字数上限は読み上げタブにあります。超えた分は切って、末尾に … を付けて読みます。表示の文字数上限とは別です。

## テスター

各イベント（コメント／ギフト／フォロー／シェア／スーパーファン／宝箱／ポータル／いいね／入室）にテスト送信があります。スーパーファンは加入とボックス、入室は通常とポータル経由で文言を分けられます。同じ人の加入が数秒以内に二重で来たときは 1 件にします。コメントタブではメンレベ（1 / 10 / 15 / 20 / 25）、停止メンレベ、スーパーファン、モデ、配信者でも送れます。ギフトタブではダイヤ数ごとの色も確認できます。  
アプリのコメント画面と、配信ソースに出ます。オーバーレイタブのプレビューは例の行が最初から出ています。読み上げテストの音はアプリ本体から再生されます。上の **サンプル** から、コメント画面だけ／配信ソースだけのサンプルと消去もできます。
読み上げタブの声の横にある **読み上げテスト** は、下の文言をそのまま読みます（コメント用テンプレートは通しません）。英語の声を試すときは英語を入れてください。テスト送信や読み上げテストの直前にも、今の入力を保存します。

画面上の **操作** メニューから、**読み上げを飛ばす**（今聞こえている音を止めて次へ）／**読み上げの待ちを捨てる**（まだ再生していない読み上げを捨てる。今聞こえている音はそのまま）／**固定枠の待ちを捨てる**／**一時停止**（初期 F7）／**サウンドミュート**（初期 F6）が使えます。接続と切断はメニューの外です。一時停止中も待ちには積まれ、再開すると続きから読みます。キーの有無に関係なく、これらのボタンは使えます。キーはアプリタブで、ボタンを押してから好きなキーを押し込んで決めます。Shift+F8 や Ctrl+Shift+F8 のように修飾キーも一緒に押せます。**消す** でキーだけ無効にできます。初期は F8 / F9 / F10 / F7 / F6 です。

読み上げタブの **同時に待つ読み上げの上限** を超えたコメントは読み上げません。捨てたときは画面下に知らせます。

トレイ常駐、アプリの明るさ、ショートカット、プロファイル、ログの保存は **アプリ** タブにあります。PC標準は Windows のライト／ダークに合わせます。コメント画面と設定画面の色です。配信ソースはオーバーレイタブのままです。

同じタブの **プロファイル** で、プロファイル名を付けて見た目・読み上げ・フィルタなどを保存し、切断中だけ切り替えられます。保存済みから選んで **適用** します。TikTok ID とポートはプロファイルでは変わりません。**プロファイルを書き出す** / **プロファイルを読み込む** でファイルに保存して戻せます（ID・ポートは含みません）。**設定を初期化する** は文言・見た目・読み上げなどを最初の状態に戻し、TikTok ID とポートは残します。各タブの一番下の **このタブを初期化する** は、そのタブの設定だけ戻します。オーバーレイのポートと、アプリタブのプロファイルは残します。初期化と読み込みは確認してから実行されます。別のPCでは VOICEVOXの場所を直してください。

配信が終わると、アプリは手動で切断したときと同じように止まります。自動では再接続しません。

## よくある質問

### LIVE Studio を見なくてもコメントは分かる

アプリ上部の **コメント** に、コメント・ギフト（アイコン付き）・フォローなどが出ます。公式のギフト演出は出ません。音や演出は TikFinity 側のまま使えます。

### アプリに出ない人がいる

LIVE Studio のチャットと、コメ読みちゃんのコメント画面は別経路です。Studio に見えていても、アプリ側に届かないことがあります。ハートミーやギフトを投げたことがない人を、アプリ側で除外してはいません。TikTok が非公式の接続へ送るコメントは、本体（ログイン中）より少ないことがあります。初めて来た人・交流が少ない人のコメントが届かない、という報告があります。ギフトを投げた人に偏って見えることがありますが、ギフト有無の判定ではありません。ブロックや NG ワードに入っている人は出ません。TikFinity など同じ仕組みのツールでも、同じ欠け方になります。切り分けは、設定タブの **ログを保存** にその人の行があるかを見てください。ログにも無ければ、アプリには届いていません。

届くコメントを増やしたいときは、配信者アカウントの TikTok cookie を `.env` に設定できます（下記 **TikTok セッション認証**）。100% 埋まる保証はありません。

### スパファンが入室したのに「なりました」と出る

**スーパーファンになりました** は、配信中に **新しく加入した** ときの文言です。既にスパファンの人が **入室した** だけでは出しません（入室は **入室** 欄の表示がオンなら `{user}さんが入室しました`）。スパファンボックスを投げたときは別の文言です。

### TikTok セッション認証（任意）

`.env` に配信者アカウントの cookie を入れると、届くコメントが増えることがあります。

1. ブラウザで TikTok にログイン（配信に使うアカウント）
2. 開発者ツール → アプリケーション → Cookie から `sessionid` と `tt-target-idc` をコピー
3. プロジェクトの `.env` に次を書く（`.env` は Git に含めない）

```
TIKTOK_SESSION_ID=（sessionid の値）
TIKTOK_TARGET_IDC=（tt-target-idc の値）
TIKTOK_AUTHENTICATE_WS=1
```

`TIKTOK_AUTHENTICATE_WS=1` を付けると、署名サービス経由で WebSocket も認証されます。**cookie が外部サービスに渡る** ため、自己責任で使ってください。付けない場合は cookie を載せても WebSocket 認証はオフのままです。設定後はアプリを再起動してください。

### 読み上げが止まらない

画面上の **読み上げを飛ばす** か **読み上げの待ちを捨てる** を使ってください。待ちの上限は読み上げタブで変えられます。固定枠が溜まっているときは **固定枠の待ちを捨てる** です。

### LIVE Studio の URL

`http://127.0.0.1:...` は弾かれます。オーバーレイタブの **LIVE Studio用をコピー**（`lvh.me`）を貼ってください。待ち受け自体は `127.0.0.1` のままです。

### 読み上げが配信に乗らない

読み上げ・ギフトサウンド・コメントサウンドは、どれもアプリ本体から出ます。OBS などでアプリの音声をキャプチャしてください。配信ソース（ブラウザソース）からは音は出ません。

### 声が二重に聞こえる

アプリの音と、別ツール（TikFinity など）の音が重なっていることが多いです。アプリ側か、もう一方の読み上げ／効果音をオフにしてください。

### 接続できない

配信開始後に接続してください。ID の打ち間違い、年齢制限、TikTok 側の一時障害でも失敗します。ログに「Business plan」や署名エラーが出るときは、コメント接続用の外部サービスが要求を拒否しています。時間をおいて再試行してください。ギフト一覧だけ取れなくても、コメントの受信自体はできることがあります。

### 配信ソースに出ない

オーバーレイタブの **コメント** で **LIVE Studio用をコピー** の URL を貼ってください（`127.0.0.1` や OBS 用は LIVE Studio では通りません）。イベントアラートやランキングが出ないときは、**アラート** や **ランキング** の URL を別ソースとして貼っているかも確認してください。オーバーレイタブの配信ソースの状態も確認してください。サーバーが止まっているときは、前のコメ読みちゃんを閉じるかポート番号を変えて再起動します。サーバーは起動中で「未接続」のときは、URL を貼り直してソースを更新してください。固定枠はコメント列と同じ画面です。

### ギフトが二重に見える

TikFinity のギフト演出を残していると、アラートとコメント列の両方に出ます。想定どおりです。コメント列だけにしたい場合は、TikFinity 側のチャット／TTS をオフにしてください。

### ×で閉じてもトレイに残る

初期値はオフです。設定の **アプリ** タブにある「×ボタンでトレイに最小化」をオンにすると、閉じてもトレイに残ります。

### 英語の声で無音

読み上げテストの文言が日本語のままです。英語を入れてからテストしてください。日本語の配信コメントには Haruka を使ってください。

### Haruka で英語は読める

読めます。日本語の声なので英語はなまります。Zira に日本語を渡すとほぼ無音になります。

### VOICEVOX のクレジット

読み上げタブの **クレジットをコピー** で文章が取れます。貼る先は配信の概要欄やパネルです。アプリのヘルプだけだと足りません。

### VOICEVOX に繋がらない

読み上げタブの **VOICEVOXを起動** を押すか、VOICEVOX 本体を起動してから「声を再取得」してください。ポートは通常 50021 です。`VOICEVOX.exe` が見つからないときは参照で場所を指定します。

### ポートが使えない

設定のポート番号を変えてください。待ち受けは `127.0.0.1` のみです。数字が範囲外のときは保存されないので、1024〜65535 にしてください。前のコメ読みちゃんが残っているときも同じ表示になります。そのときは前の窓を閉じてから、もう一度起動してください。コメント画面と接続はそのままで使えます。
