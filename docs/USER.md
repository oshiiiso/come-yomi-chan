# コメ読みちゃん 使い方

自分の TikTok LIVE のコメントやギフトを、このアプリのコメント画面で見ながら、配信画面の上にコメント列として出し、Windows 内蔵TTS または VOICEVOX で読み上げます。

TikTok LIVE Studio のリンクソースと、OBS のブラウザソースに、それぞれ用の URL を 1 本足す使い方です。ギフトの公式演出やフォロー音は TikFinity 側のままで問題ありません。

> **個人・身内利用向け**  
> TikTok 側の仕様変更で動かなくなることがあります。

## 準備

1. コメ読みちゃん を起動する（最初に、やることを3つ出します。下にコメント欄も見えます。**サンプルを見る** で例の行を出せます。案内はそのままです。**サンプルを消す** で消せます）。デスクトップのショートカットが Electron の絵のままだったら、一度起動してからショートカットを作り直してください
2. 画面の案内どおり、TikTok ID を入れて **接続** し、出てきたアイコンと名前が自分か確認する
3. コメントを自分で見るだけなら、これで使えます。視聴者の画面にも出すときは、設定の **LIVE Studio用をコピー** を使います

読み上げは最初から Windows 内蔵TTS です。VOICEVOX にしたいときは、あとから読み上げタブで変えられます。VOICEVOX を選んでいても、本体が起動していないときは内蔵TTSで読み上げます。

## 初期設定

アプリが案内します。

1. **設定で ID を入れる**（先頭の `@` は不要）
2. **接続する** → アイコンと名前が出るので、自分か確認して **この人で接続**
3. TikTok で配信を開始する（LIVE Studio でもスマホでも可）

コメント欄の見た目は、最初から下に空の欄が出ます。**サンプルを見る** でコメント・ギフト・フォローの例を出せます（音は出ません。配信ソースにも出ません）。案内はそのまま残ります。同じ案内の **サンプルを消す** で消せます。上の **サンプル** の **コメント画面を消す** でも同じです。

接続できるとコメント画面に流れます。視聴者の画面にコメント列を乗せるときは、接続タブの **LIVE Studio用をコピー** を、LIVE Studio の **ソース追加 → リンク** に貼ります。

毎回自動で始めたいときは、接続タブの **起動時に配信へ接続する** をオンにします。起動時につながるのは、一度アイコンと名前で確認した ID だけです。

接続・切断・読み上げを飛ばす／読み上げの待ちを捨てる／固定枠の待ちを捨てるは、コメント画面のままで使えます。初期は **F8** で今の読み上げを飛ばし、**F9** で読み上げの待ちを捨て、**F10** で固定枠の表示と待ちを捨てます（入力欄にいるときは効きません。キーはアプリタブで変えたり消したりできます。3つのキーは別にしてください。Shift や Ctrl との組み合わせも使えます。消しても画面のボタンは使えます）。上の **窓** から **手前に置く** と **コンパクトな窓** を切り替えられます。アプリタブからも同じ設定ができます。上の **サンプル** からコメント画面／配信ソースのサンプルと消去ができます。配信ソースのサンプルは **配信の見た目** タブにもあります。ログの保存はアプリタブです。

設定のタブは次のとおりです。

- **接続** … TikTok ID、オーバーレイ URL、起動時に接続する
- **フィルタ** … NGワード、ブロックするユーザー、ミュートするユーザー
- **コメント** … 文言、印の色、読み上げ条件
- **ギフト / イベント** … 配信ソースへの表示と読み上げ。イベントは種類を選んで1つずつ出す
- **配信の見た目** … 視聴者の画面（配信ソース）の見た目。コメント画面の文字や欄はコメント画面の上。このタブだけ右側にプレビューが出る。幅は境界をドラッグして変えられる
- **読み上げ** … 声とエンジン
- **アプリ** … 常に手前、コンパクト窓、トレイ常駐、アプリの明るさ、ショートカット、ログの保存、設定の書き出し／読み込み／初期化

### コメント画面のレイアウト

コメント画面は左がコメント、右がギフト・フォローなどです。上の **まとめる / 分ける / 自由配置** で欄を変えられます。まとめるは 1 列、分けるはコメントとその他の 2 列です。分けているときは境界をドラッグすると幅を変えられます。ダブルクリックで初期の幅に戻ります。

**自由配置** では欄の見出しを他の欄の端へドラッグすると左右・上下に分割できます。種類のラベルを中央へドロップするとその欄へ移せます。窓の数は、今表示している種類の数までです。表示をオフにした種類だけの窓は消えます。まとめる／分ける／自由配置と、自由配置での移動は変えたときに保存されます。上の **文字** スライダーでコメント画面の文字の大きさを変えられます（10〜30px、初期は20px。配信ソースの見た目は変わりません）。

### コメント画面の印

ファンクラブ加入者は名前の左に印が出ます。TikTok のファンクラブ名が取れたら **ゆうれい5** のように名前とレベ、取れなければ **メンレベ5** です。停止中（しばらくポイントが無い人）は同じ印の色が灰色になります。未加入は印なしです。色はコメントタブの **メンレベの色** で、境目（初期は 1 / 10 / 15 / 20 / 25）と色を変えられます。スーパーファンは **スパファン**、配信のモデレーターは **モデ**、配信者本人は **配信者** と出ます。ギフトはダイヤ数が大きいほど左の色が目立ちます（灰 → 黄 → 橙 → ピンク）。

### コメント画面の表示と検索

上の **この画面** で、ギフト・フォロー・シェア・スパファン・宝箱・ポータル・いいね・入室をコメント画面に出すかを切り替えます（配信ソースと読み上げは変わりません。読み上げは設定の各タブです）。オンの種類は色が付きます。コメントは常に出ます。各タブの **配信ソース** をオフにしていても、コメント画面の **この画面** がオンならこちらに出ます。お楽しみ袋はギフトとして出ます。ポータル経由の入室は **入室** の表示に従います。

**検索** に名前・ID・本文を入れると、一致しない行を隠します。行をクリックすると、同じ人の行だけが目立つようになります。もう一度クリックするか、余白をクリックすると解除します。

### コメント画面の右クリック

行を右クリックすると、**コメントをコピー** / **IDをコピー** / **ニックネームをコピー**、その人の **ミュート**（読み上げしない）、**ブロック**（表示も読み上げもしない）ができます。IDは @ なしです。

### コメント画面のログ

古い行は欄ごとに 300 件を超えると消えます。上にスクロールしているときはその欄だけ自動では下りず、**最新へ** で最新に戻れます。上の **サンプル** の **コメント画面にサンプル** で、コメント・ギフト・フォローの例を音なしで出せます（配信ソースには出ません）。**コメント画面を消す** は表示だけ消します。保存する行はそのまま残ります。**配信ソースにサンプル** は、今出ている配信ソースを消してから、コメント・ギフト・フォローの3件を出します。固定枠がオンならギフトはコメントのすぐ上、フォローはそのあと枠に切り替わります。配信中に押すと、配信ソフトに貼った画面も一度空になります。**配信ソースを消す** は、配信ソフトに貼ったコメント列と固定枠だけを対象にします（コメント画面は変わりません）。同じボタンは **配信の見た目** タブにもあります。アプリタブの **ログを保存** で、アプリを開いてから流れた行をテキスト（txt）に書き出せます。中身はタブ区切りなので、表計算ソフトでも開けます。

### TikTok LIVE Studio

1. ソース追加 → **リンク**
2. **LIVE Studio用をコピー** したアドレスを貼る（`127.0.0.1` は弾かれます）
3. 通らないときだけ **別のURLをコピー**（`overlay.localhost`）を試す
4. 位置とサイズを調整する
5. **音声をオンにする** はオンのままにする

### OBS（録画）

1. ソース追加 → **ブラウザ**
2. 接続タブの **OBS用をコピー**（`127.0.0.1`）を貼る
3. 幅・高さはシーンに合わせる
4. 自分の耳に二重で聞こえるときは、このブラウザソースの**音声モニタリングをオフ**にする  
   （配信には LIVE Studio 側の音、録画には OBS 側の音が乗ります）

## テンプレート

コメントとギフトは、表示と読み上げを別々に書けます。変数以外の文章もそのまま使えます。

| 変数 | 内容 |
|---|---|
| `{user}` | ニックネーム |
| `{comment}` | コメント本文 |
| `{gift}` | ギフト名 |
| `{count}` | ギフト個数。1個のときは空。2個以上は表示が `×100`、読み上げが `100こ` |
| `{likes}` | いいねの累計（数字のまま） |

`@` や `＠` で始まるコメントは、コメントタブの **@から始まるコメントは読み上げない** がオンなら表示だけします。**URLは読み上げない** がオンなら、http / www / discord.gg のリンクは読みません。文言があるコメントはリンクの部分だけ飛ばし、リンクだけのときは名前も読みません。**配信者のコメントは読み上げない** がオンなら、配信者本人のコメントは表示だけします。**絵文字だけのコメントは読み上げない** がオンなら、スタンプや絵文字だけのコメントは読みません。

**メンレベとスーパーファンのコメントだけ読む** をオンにすると、条件を満たすコメントだけ読みます。初期はオフで、全員読みます。オンのときは **メンレベは何以上を読む** と **スーパーファンは読む** が使えます。メンレベ未加入のスーパーファンも、スーパーファンは読むがオンなら読みます。ギフトやフォローの読み上げはこの条件の外です。**同じ人の連投は読み上げない**（最初はオフ）は、短い間隔で同じ人が続けて書いたコメントを表示だけにします。間隔は秒で変えられます。

フィルタタブの **ブロックするユーザー** に TikTok ID か表示名を改行で書くと、その人のコメント・ギフトなどは表示も読み上げもしません。**ミュートするユーザー** は読み上げだけ止めます。NGワードは文言、ブロックとミュートは人です。コメント画面の右クリックからも追加・解除できます。

**名前を出さない**（配信の見た目タブ）をオンにすると、配信ソースのコメント列からニックネームが消えます。ギフトやフォローの表示にも効きます。このアプリのコメント画面には名前が出ます。読み上げはテンプレートのままです。

読み上げテンプレートの **半角ピリオド `.`** は無音の拍です。句点にしたいときは `。` を使ってください。

例:

- `{user}.{comment}` → テストユーザー（拍）テストコメントです
- `{user}さんから{gift}{count}` → 1個なら `テストさんからバラ`、100個なら表示 `テストさんからバラ×100`

設定は変えたらすぐ保存されます。数字が範囲外のときは保存せず、画面下に知らせます。直すとその内容で保存されます。

## いいね

いいねは視聴者ごとに数えます。イベントタブで区切り（例: 100）を指定すると、その人の累計が 100・200・300… をまたいだときだけ表示／読み上げます。連打そのものは出しません。

## ポータル

ポータルを投げたときはイベントタブの **ポータル** で表示・読み上げします。経由入室は **入室** の表示・読み上げに従い、文言だけ分けます（通常は `{user}さんが入室しました`、経由は `ポータルから{user}さんが入室しました`）。コメント画面の **表示** も、投げはポータル、経由入室は入室です。初期は投げがオン、入室がオフです。

## VOICEVOX

1. [VOICEVOX](https://voicevox.hiroshiba.jp/) を入れる（エンジンは通常 `127.0.0.1:50021`）
2. 読み上げタブでエンジンを **VOICEVOX** にする
3. **VOICEVOXの場所** が空なら、よくあるインストール先を探します。見つからなければ **参照** で `VOICEVOX.exe` を選ぶ
4. **VOICEVOXを起動** を押す（または VOICEVOX 本体を自分で起動する）
5. 声の横の **声を再取得** でキャラを選ぶ
6. 毎回一緒に立ち上げたいときは **コメ読みちゃん起動時にVOICEVOXも起動する** をオンにする
7. **クレジットをコピー** して、TikTok / YouTube などの**概要欄やパネル**に貼る

このアプリを終了しても VOICEVOX は閉じません。使うキャラの利用規約でクレジットが必要な場合、アプリ内に書いてあるだけでは足りません。視聴者が見られる場所に `VOICEVOX:ずんだもん` のように載せてください。

## 配信の見た目

**配信の見た目** タブは視聴者の画面（配信ソース）用です。コメント画面の文字サイズや欄は、コメント画面の上で変えます。このタブを開くと、右側にプレビューが出ます。境界をドラッグすると幅を変えられます。ダブルクリックで元の幅に戻します。市松模様は「背景が透明かどうか」を見るためのもので、LIVE Studio / OBS に貼ったソースの背景は透明のままです。グリーンやマゼンタにも切り替えられます。他の設定タブではプレビューは出しません。タブ先頭の **配信ソースにサンプル** / **配信ソースを消す** でも確認できます。

**配信の見た目** タブのかんたん設定で、CSS を書かなくても変えられます。**動き** でコメントの出方（ふわっと／フェード／スライドなど）を選べます。**速さ** はとても遅い〜とても速いの5段階です。初期値はふわっと・ふつうです。色のプリセットを押しても動きは変わりません。配信中に変えたときは、次に出る行から効きます。プレビューは選ぶと再生されます。**動きを見る** でももう一度確認できます。

1. プリセットを選ぶ（標準 / 明るい / 文字だけ / ネオン）
2. フォント・文字サイズ（10〜30px、初期は20px）・背景の濃さ・角の丸み・ギフトアイコン・位置を調整する。ネオンを選ぶと **ネオンの色** バーが出ます
3. 右側のプレビューで確認する（最初からコメント／ギフト／フォローの例が出ています。スライダーとフォントはすぐ反映されます）
4. スライダーを動かすと、少し待って配信ソースにも保存されます

表示行数・表示時間・**文字数上限** も配信の見た目タブの「コメント列」にあります。長いコメントは … で切れます。**時間で消えない** をオンにすると、秒数では消えず、表示行数を超えた古い行だけ消えます。

同じ「コメント列」に **固定枠** があります。**固定枠を使う** をオフにすると、今までどおり全部下から流れます。オンのとき、ギフト・フォローなどはコメント列のすぐ上に1件ずつ出します。来た順で、今の行が消えてから次です。枠の色はコメント列と違います（標準はオレンジ、ネオンは今の色からずらした色）。動きはコメントと同じテンプレートです。初期の表示時間は4秒です。**次が無いときは出したまま** をオンにすると、待ちが無ければ枠を消しません。次が来たら今の秒数のあと切り替わります。種類ごとに「固定枠に出す／コメントと一緒に流す」も選べます。初期はコメント以外が全部固定枠です。配信中に変えたときは、今出している行はそのまま、待ちに入っている分から今の種類に従います。固定枠をオフにしたときや、出す種類が無くなったときは、出しっぱなしでも枠を消します。表示時間の途中なら、その秒数が終わるまで今の行は残ります。配信ソースは常にこの設定です。プレビューも固定枠で見るとき、種類は表示時間ごとに順に切り替わります。プレビューだけ、今までどおり全部流れる見え方にも切り替えられます。コメント画面には固定枠は出ません。待ちが溜まったときは画面上の **固定枠の待ちを捨てる**（初期 F10）で、今の表示も待ちもすぐ消えます。**配信ソースを消す** はコメント列も固定枠も消します。配信ソフトに貼った画面が古いときは、ブラウザソースを更新してください。

上級者向けのカスタム CSS は、配信の見た目タブの一番下に折りたたんであります。空ならかんたん設定のままです。

ギフトが来ると、コメント列の右に **そのギフトの TikTok アイコン** が出ます。ギフトタブの **読み上げする最低ダイヤ** より安いギフトは表示だけして読みません。投げたポータルにも同じ最低ダイヤが効きます。ギフトタブでテストするギフトを選べます。一覧は配信に繋がなくても、接続タブの TikTok ID から取れます。一度取れた一覧は保存されるので、次回の配信前テストにも使えます。一度も配信したことがないと取れないことがあります。一覧が空のときは仮のバラになります。

使えるクラスの例: `.chat` `.chat--pin` `.chat--pin .chat__item` `.chat__item` `.chat__body` `.chat__avatar` `.chat__gift` `.chat__item--gift` `.chat__item--portal`

読み上げの文字数上限は読み上げタブにあります。超えた分は切って、末尾に … を付けて読みます。表示の文字数上限とは別です。

## テスター

各イベント（コメント／ギフト／フォロー／シェア／スーパーファン／宝箱／ポータル／いいね／入室）にテスト送信があります。スーパーファンは加入とボックス、入室は通常とポータル経由で文言を分けられます。同じ人の加入が数秒以内に二重で来たときは 1 件にします。コメントタブではメンレベ（1 / 10 / 15 / 20 / 25）、停止メンレベ、スーパーファン、モデ、配信者でも送れます。ギフトタブではダイヤ数ごとの色も確認できます。  
アプリのコメント画面と、配信ソースに出ます。配信の見た目タブのプレビューは例の行が最初から出ています。読み上げテストの音は配信ソースから再生されます。上の **サンプル** から、コメント画面だけ／配信ソースだけのサンプルと消去もできます。
読み上げタブの声の横にある **読み上げテスト** は、下の文言をそのまま読みます（コメント用テンプレートは通しません）。英語の声を試すときは英語を入れてください。テスト送信や読み上げテストの直前にも、今の入力を保存します。

画面上の **読み上げを飛ばす** は今聞こえている音を止めて次へ進みます。**読み上げの待ちを捨てる** はまだ再生していない読み上げを捨てます（今聞こえている音はそのままです）。**固定枠の待ちを捨てる** は配信ソースの固定枠の表示と待ちをすぐ消します。コメントが多すぎて詰まっているときに使います。キーの有無に関係なく、このボタンは使えます。キーはアプリタブで、ボタンを押してから好きなキーを押し込んで決めます。Shift+F8 や Ctrl+Shift+F8 のように修飾キーも一緒に押せます。**消す** でキーだけ無効にできます。初期は F8 / F9 / F10 です。

読み上げタブの **同時に待つ読み上げの上限** を超えたコメントは読み上げません。捨てたときは画面下に知らせます。

トレイ常駐、アプリの明るさ、ショートカット、ログの保存は **アプリ** タブにあります。PC標準は Windows のライト／ダークに合わせます。コメント画面と設定画面の色です。配信ソースは配信の見た目タブのままです。同じタブの **設定を書き出す** / **設定を読み込む** でファイルに保存して戻せます。読み込むと今の設定を上書きします（TikTok ID とポートも含む）。**設定を初期化する** は文言・見た目・読み上げなどを最初の状態に戻し、TikTok ID とポートは残します。初期化と読み込みは確認してから実行されます。別のPCでは VOICEVOXの場所を直してください。

## よくある質問

### LIVE Studio を見なくてもコメントは分かる

アプリ上部の **コメント** に、コメント・ギフト（アイコン付き）・フォローなどが出ます。公式のギフト演出は出ません。音や演出は TikFinity 側のまま使えます。

### アプリに出ない人がいる

LIVE Studio のチャットと、コメ読みちゃんのコメント画面は別経路です。Studio に見えていても、アプリ側に届かないことがあります。ハートミーやギフトを投げたことがない人を、アプリ側で除外してはいません。TikTok が非公式の接続へ送るコメントは、本体（ログイン中）より少ないことがあります。初めて来た人・交流が少ない人のコメントが届かない、という報告があります。ギフトを投げた人に偏って見えることがありますが、ギフト有無の判定ではありません。ブロックや NG ワードに入っている人は出ません。TikFinity など同じ仕組みのツールでも、同じ欠け方になります。切り分けは、設定タブの **ログを保存** にその人の行があるかを見てください。ログにも無ければ、アプリには届いていません。

届くコメントを増やしたいときは、配信者アカウントの TikTok cookie を `.env` に設定できます（下記 **TikTok セッション認証**）。100% 埋まる保証はありません。

### スパファンが入室したのに「なりました」と出る

**スーパーファンになりました** は、配信中に **新しく加入した** ときの文言です。既にスパファンの人が **入室した** だけでは出しません（入室は **入室** 欄の表示がオンなら `{user}さんが入室しました`）。スパファンボックスを投げたときは別の文言です。

### TikTok セッション認証（任意）

`.env` に配信者アカウントの cookie を入れると、届くコメントが増えることがあります。

1. ブラウザで TikTok にログイン（配信に使うアカウント）
2. 開発者ツール → アプリケーション → Cookie から `sessionid` と `tt-target-idc` をコピー
3. プロジェクトの `.env` に次を書く（`.env` は Git に含めない）

```
TIKTOK_SESSION_ID=（sessionid の値）
TIKTOK_TARGET_IDC=（tt-target-idc の値）
TIKTOK_AUTHENTICATE_WS=1
```

`TIKTOK_AUTHENTICATE_WS=1` を付けると、署名サービス経由で WebSocket も認証されます。**cookie が外部サービスに渡る** ため、自己責任で使ってください。付けない場合は cookie を載せても WebSocket 認証はオフのままです。設定後はアプリを再起動してください。

### 読み上げが止まらない

画面上の **読み上げを飛ばす** か **読み上げの待ちを捨てる** を使ってください。待ちの上限は読み上げタブで変えられます。固定枠が溜まっているときは **固定枠の待ちを捨てる** です。

### LIVE Studio の URL

`http://127.0.0.1:...` は弾かれます。接続タブの **LIVE Studio用をコピー**（`lvh.me`）を貼ってください。待ち受け自体は `127.0.0.1` のままです。

### 読み上げが配信に乗らない

オーバーレイの URL がソースに入っているか確認してください。音はオーバーレイのページ側で再生されます。

### 声が二重に聞こえる

LIVE Studio と OBS の両方でコメント列を開いているためです。OBS 側のモニタリングをオフにしてください。

### 接続できない

配信開始後に接続してください。ID の打ち間違い、年齢制限、TikTok 側の一時障害でも失敗します。ログに「Business plan」や署名エラーが出るときは、コメント接続用の外部サービスが要求を拒否しています。時間をおいて再試行してください。ギフト一覧だけ取れなくても、コメントの受信自体はできることがあります。

### 配信ソースに出ない

接続タブの **LIVE Studio用をコピー** の URL を貼ってください（`127.0.0.1` や OBS 用は LIVE Studio では通りません）。接続タブ下の配信ソースの状態も確認してください。サーバーが止まっているときは、前のコメ読みちゃんを閉じるかポート番号を変えて再起動します。サーバーは起動中で「未接続」のときは、URL を貼り直してソースを更新してください。固定枠も同じ画面です。

### ギフトが二重に見える

TikFinity のギフト演出を残していると、アラートとコメント列の両方に出ます。想定どおりです。コメント列だけにしたい場合は、TikFinity 側のチャット／TTS をオフにしてください。

### ×で閉じてもトレイに残る

初期値はオフです。設定の **アプリ** タブにある「×ボタンでトレイに最小化」をオンにすると、閉じてもトレイに残ります。

### 英語の声で無音

読み上げテストの文言が日本語のままです。英語を入れてからテストしてください。日本語の配信コメントには Haruka を使ってください。

### Haruka で英語は読める

読めます。日本語の声なので英語はなまります。Zira に日本語を渡すとほぼ無音になります。

### VOICEVOX のクレジット

読み上げタブの **クレジットをコピー** で文章が取れます。貼る先は配信の概要欄やパネルです。アプリのヘルプだけだと足りません。

### VOICEVOX に繋がらない

読み上げタブの **VOICEVOXを起動** を押すか、VOICEVOX 本体を起動してから「声を再取得」してください。ポートは通常 50021 です。`VOICEVOX.exe` が見つからないときは参照で場所を指定します。

### ポートが使えない

設定のポート番号を変えてください。待ち受けは `127.0.0.1` のみです。数字が範囲外のときは保存されないので、1024〜65535 にしてください。前のコメ読みちゃんが残っているときも同じ表示になります。そのときは前の窓を閉じてから、もう一度起動してください。コメント画面と接続はそのままで使えます。
