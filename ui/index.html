      はじめて使うとき

      1. 下に自分の TikTok ID を入れる（先頭の @ は不要）
      2. 画面上の 接続 を押す
      3. 出てきたアイコンと名前が自分か確認して、この人で接続する
      4. いつものように TikTok で配信を開始する

      コメントを自分で見るだけなら、これで終わりです。視聴者の画面にもコメント列を出すときは、その下の URL をコピーします。

      TikTok ID

      プロフィールの @ の後ろです。接続の前に、アイコンと名前で本人か確認します。他の配信ツールと同時に起動しても大丈夫です。

      視聴者の画面にコメントを乗せる

      TikTok LIVE Studio で ソース追加 → リンク を選び、下のアドレスを貼ってください。

      「正しいURLを入力してください」と出るときは、127.0.0.1 を手打ちしていないか確認してください。上のコピーを使います。

      OBS

      OBS のブラウザソースに下のアドレスを貼ってください。自分の耳に二重で聞こえるときは、このソースの音声モニタリングをオフにしてください。

      別のURL

      LIVE Studio で上のアドレスが通らないときだけ使います。

      ポートを変えると、上の URL も変わります。配信ソフトに貼り直してください。

      起動

      TikTok ID が入っているとき、起動後に接続を始めます。前回確認した ID のまま使います。ID を変えたあとは、もう一度接続して相手を確認してください。

      NGワード

      コメント本文や表示テキストに含まれていると、そのイベントを落とします。

      ブロックするユーザー

      その人のコメント・ギフトなどは表示も読み上げもしません。コメント画面の右クリックからも追加できます。

      ミュートするユーザー

      読み上げしません。コメント画面と配信ソースには出ます。NGワードは文言、ブロックは表示ごと、ミュートは読み上げだけです。

      ウィンドウ

      配信画面やブラウザの上に、コメント画面を重ねられます。コメント画面の「手前」と同じです。

      細い窓にしてコメント画面を出します。サブモニターや配信の横に置くときに使います。

      オフのときは × で終了します。配信中だけトレイに残したいときにオンにしてください。

      Windows のライト／ダークに合わせます。コメント画面と設定画面の色です。配信ソースの見た目は配信の見た目タブで変えます。

      ショートカット

      ボタンを押してから、使いたいキーを押します。入力欄にいるときは効きません。

      コメントログ

      アプリを開いてから流れた行をテキストに書き出せます。中身はタブ区切りです。

      設定

      ファイルに書き出して、別のPCや再インストール後に戻せます。VOICEVOXの場所は別のPCだと直してください。

      文言・見た目・読み上げ・フィルタなどを最初の状態に戻します。TikTok ID と配信画面用のポートは残します。

      文言

      {user} と {comment} が使えます。例: {user}.{comment}

      印

      メンレベの色

      このレベ以上で印の色が変わります。印はファンクラブ名＋レベ、取れないときはメンレベ＋数字です。

      読み上げ条件

      TikTok のメンション（@ユーザー名）は表示だけして、読み上げを飛ばします。

      表示はそのままです。http・www・discord.gg のリンクは読みません。リンクだけのときは名前も読みません。

      配信者本人のコメントは表示だけします。ギフトやフォローはそのままです。

      スタンプや絵文字だけのときは、表示はそのまま、読み上げを飛ばします。

      オフのときは全員読みます。オンのときだけ下の条件が効きます。ギフトやフォローはそのままです。

      メンレベ未加入でもスーパーファンなら読みます。

      短い間隔で同じ人が続けてコメントしたとき、表示はして読み上げだけ飛ばします。

      ギフト

      {count} は1個のとき空、2個以上は表示が ×100、読み上げが 100こ になります。配信中は投げられたギフトの TikTok アイコンが出ます。

      0 なら安いギフトも読みます。表示はダイヤに関係なく出ます。

      配信前でも接続タブの TikTok ID から一覧を取れます。一度取れた一覧は保存されます。一度も配信していないと失敗することがあります。空のときは仮のバラになります。

      コメント画面のギフト色はダイヤ数で変わります。下で帯を確認できます。

      スーパーファン

      配信の月額加入とスーパーファンボックスです。同じ人の加入が短時間に二重で来たときは1件にします。

      宝箱

      視聴者が投げた宝箱です。お楽しみ袋はギフトとして出ます。

      ポータル

      視聴者が投げたポータルです。経由入室は入室タブです。

      いいね

      視聴者ごとに累計し、指定した数の区切りをまたいだときだけ出します。例: 100 なら 100・200・300…

      {user} と {likes} が使えます。{likes} はその時点の累計です。

      入室

      通常入室とポータル経由で文言を分けます。表示と読み上げはこの入室の設定です。人数が多い配信ではオフ推奨です。

      ここは視聴者の画面（配信ソース）の見た目です。コメント画面の文字サイズや欄は、コメント画面の上で変えます。

      かんたん見た目

      プリセットを選んでから、スライダーで微調整できます。このタブは少し待つと配信ソースにも保存されます。

      ニックネームは配信ソースのコメント列から消えます。ギフトやフォローにも効きます。このアプリのコメント画面には名前が出ます。読み上げはテンプレートのままです。

      速さ

      コメントが出るときと消えるときの動きです。次に出る行から効きます。プレビューは選ぶと再生されます。

      コメント列

      時間で消えないときは、表示行数を超えた古い行だけ消えます。長いコメントは文字数上限で切り、末尾に … を付けます。読み上げ側の上限は読み上げタブです。

      固定枠

      ギフトなどはコメント列のすぐ上に1件ずつ出します。来た順です。コメント画面には出ません。

      オフにすると、今までどおり全部下から流れます。

      オンのとき、待ちが無ければ枠を消しません。次が来たら今の秒数のあと切り替わります。

      固定枠に出す種類

      オフにすると、その種類はコメントと一緒に流れます。初期はコメント以外が全部固定枠です。

      オフにすると、プレビューだけ今までどおり全部流れます。配信ソースは常に上の設定です。

      カスタム CSS（上級者向け）

      .chat / .chat--pin / .chat--pin .chat__item / .chat__item / .chat__body / .chat__avatar / .chat__gift / .chat__item--gift などが使えます。

      読み上げエンジン

      VOICEVOX 本体のインストールが必要です。場所が空ならよくあるインストール先を探します。

      このアプリを終了しても VOICEVOX は閉じません。

      接続先（通常は変更不要）

      待ち受けは 127.0.0.1 のみです。

      声

      VOICEVOX を起動したあとや、エンジンを切り替えたあとに声が出ないときは再取得してください。

      声の横の読み上げテストで、この文言をテンプレートなしでそのまま読みます。速度は VOICEVOX の話速にも使います。詰まっているときは画面上の「読み上げを飛ばす」「読み上げの待ちを捨てる」を使います。

      超えた分は切って、末尾に … を付けて読みます。表示の上限とは別です。

      上限を超えたコメントは読み上げません。捨てたときは画面下に知らせます。

      VOICEVOX クレジット

      使うキャラの利用規約でクレジットが必要な場合は、配信の概要欄やパネルに貼ってください。アプリ内だけだと足りません。
